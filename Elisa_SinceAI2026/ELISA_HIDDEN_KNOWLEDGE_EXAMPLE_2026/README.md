# Elisa × Since AI 2026 — example material

Challenge: **Capturing and Linking Human-Generated Contextual Metadata for Autonomous Network Operations**
Guiding question: *How could we collect silent metadata without creating additional work for our specialists?*

This is the example material Elisa provides for the challenge. It is deliberately small: one real-type case, told in the channels where such knowledge actually lives. Read the challenge brief first.

| File | Content |
|---|---|
| `use_case.md` | The hidden-expert-knowledge case in plain language, plus the locked-barrier access example |
| `teams_chat.json` | The same case as a Teams conversation (12 messages, machine-readable) |
| `email.txt` | The same case as an email |
| `reference_architecture.png` | Elisa's data-layer and context architecture: time-aware layers; each context assertion is bound to a graph entity and has `valid_from` / `valid_to` |

## Ground rules

- Names, node IDs and messages are illustrative. No production, customer or personal data. No access to Elisa systems is provided or needed.
- You may generate more synthetic conversations, emails and simple network records in the same style (other devices, advice that becomes outdated, conflicting advice). Document what you generated and how.
- Submit a working demo, pitch slides, documentation and a code repository through the Since AI app by **Sunday 8 November 2026, 10:00**.
